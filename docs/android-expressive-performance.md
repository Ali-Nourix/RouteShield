# Android Expressive + connection refresh

## Design token plan

RouteShield's job is to connect safely, choose a route, and selectively bypass applications. Each destination has one clear main action: Connect/Disconnect, import/select server, app routing, preferences.

- Color: preserve the user's seed and generated light/dark role schemes. Vibrant seed-derived role scheme. The connection control uses primary/onPrimary and active tertiaryContainer/onTertiaryContainer, active routes secondaryContainer, grouped settings surfaceContainerLow, traffic figures tertiary. No gradients, blur, or decorative statistic cards.
- Shape: the primary power control morphs between official Cookie9Sided and Puffy polygons; quality uses asymmetric 32dp/8dp corners, grouped content 24dp, server rows 20dp selected / 8dp idle, standard button shape morph. State transitions use the Expressive motion scheme, with radius clamped above zero.
- Type: emphasized connection status and traffic figures; Persian uses zero tracking and increased line height. Body text remains readable at 200% font scale.
- Motion: restrained spatial spring for selected route shape; effects spring for state colors. No endless bouncing or animation on every row.
- Layout: flexible page app bar instead of duplicate brand + giant title; compact profile header, segmented server rows, large primary connect action, responsive traffic grouping. Detail explanations expand only when needed.

## Connection scope

Parallel bounded HTTPS health checks, successful-probe-only latency, adaptive recovery cadence and physical-network-change rechecks. Preserve encrypted DNS, certificate verification, full-family TUN capture, manual route choices, and fail-closed recovery. No bandwidth guarantee or modified third-party libbox binary. Native urltest ranks HTTPS responsiveness, not download throughput.

## User reference refinement

The owner supplied official M3 Expressive examples and asked for an avant-garde VPN-specific treatment, not merely tidier cards. The home surface now uses emphasized 45sp typography, a real state-driven Material polygon power control, a Vibrant role palette, and an asymmetric quality surface with pill-bar history. Bars are made only from actual bounded HTTPS samples; failures are explicit gray gaps, and empty states never invent speed. Shapes spring only on meaningful interaction/state changes. The chart is RTT, not bandwidth; fixture screenshots are clearly named and do not claim device measurements.

## Validation / device gates

Run full Kotlin compilation, unit/Robolectric UI tests, lint, and both diagnostic and release packaging. Cover light/dark, Persian RTL, 200% font scale, tablet rail, route sheet and Disconnect. A phone test remains required for actual throughput, sustained quality, Wi-Fi/mobile handover, owner-signed package upgrade, TLS/DNS/IPv6 leakage and Android lockdown. No certificate, keystore, insecure TLS, or direct-fallback policy is changed.
